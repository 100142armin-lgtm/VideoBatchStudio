VideoBatchStudio 团队版：安装与模型准备

1. 下载 VideoBatchStudio_Portable.zip，完整解压到个人文件夹。
   不要在 ZIP 压缩包内部直接运行，不要只下载单个 EXE。
2. 双击 Start_VideoBatchStudio.cmd（或“双击启动软件.bat”）。
   缺少 .NET Framework 4.8 时，会打开经过微软数字签名验证的安装程序。
   Windows 要求管理员确认或重启时，请按系统提示操作。
3. 基础视频处理、下载、Edge-TTS 运行环境、Whisper CPU 与 Base 模型随完整包提供。
   软件右下角“组件 / 模型”可检查并修复，或运行 Install_Components.cmd。
   首次在新电脑运行，微软 VC++ / WebView2 运行库可能仍需安装。
4. 新手点击“安装推荐组件”，等待每项显示“已就绪”。失败会显示原因，可重试；已完成的项目保留。
5. 需要更高精度字幕，可勾选 Small / Turbo / Large-v3 模型后点击“安装勾选项”。
6. 需要本地配音，勾选 Chatterbox。建议安装时预留 18 GB 空间。
   安装程序自动选择 NVIDIA / CPU 运行库。CPU 可用但生成较慢；NVIDIA 加速需要兼容驱动。
   初次安装模型需要联网，模型安装完整后 Chatterbox 配音和 Whisper 识别可离线使用。
7. Edge-TTS、ElevenLabs 和视频下载本身需要联网。ElevenLabs 使用您自己的账户 Key。
   本软件安装包不包含开发者的 Key、参考声音、素材路径或私人配置。
8. 字幕、BGM、标题、水印和参考音频按每位用户自己的需求设置。

系统：64 位 Windows 10 / 11。微软系统组件和显卡驱动的安装权限由 Windows 管理。
不要关闭杀毒软件或添加整个磁盘的排除项。若系统拦截安装，保留提示并联系维护人员。
第三方组件的许可证见 licenses、fonts/OFL.txt、Python 的 LICENSE 和各包的 dist-info 目录。

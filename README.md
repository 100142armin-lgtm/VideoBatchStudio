# 视频批处理工具 (VideoBatchStudio) V7.5

Windows 桌面音视频批处理工具，提供批量合并、视频拆分、动态水印、视频拼屏（多格分屏与画中画）和图片成片五大核心能力。

## 主要特性

1. **批量合并**：
   - 智能相似度画面分析与自动聚类排序
   - 来源文件夹交叉轮巡排序
   - 每组数量、额外重复次数与最大输出限制
   - 尾组防落单自动重排平衡（例如 3+3+1 自动调整为 3+2+2）
   - 严格目标时长控制，组内平均截取或随机截取，智能交替补段
   - 12 种柔和转场与无损快速合并支持

2. **视频拆分**：
   - 固定秒数（支持不足时长并入上一段或舍弃）
   - 平均等份切分（2～100 等份）
   - 自带 0.05 秒关键帧容差与失败自动逐段精准补做

3. **水印处理**：
   - 支持同时叠加 3 个文字水印与 3 个图片水印库
   - 文字水印：自由字号（4-2000）、范围折行、描边、圆角背景、安全边距
   - 图片水印：单张参与或多图轮播（Slideshow），具备真实交叉淡化与换图间隔控制
   - 动效体系：10 种入场、5 种退场、9 种循环停留动效（扫光、粒子等），支持 PNG Alpha 通道保护

4. **视频拼屏**：
   - 常用分屏模板、多格分屏（四/六/九宫格）以及画中画（单/双/三小窗）
   - 实时首帧画布预览，点选区域快速绑定素材
   - 支持“固定时长”或“跟随主区域逐条完整导出”
   - 各区域独立音量、边框样式，每条素材支持缩放与取景微调

5. **图片成片**：
   - 静态图片智能组合生成指定时长与数量的 MP4 视频
   - 杂志三联、四宫格、六宫格、九宫格等丰富排版
   - 展示律动、智能校色美化与组间平滑转场

6. **通用底层能力**：
   - 逐视频独立微调：水平翻转、倒放、横屏裁中（自动转 9:16）、缩放（0.1~3.0x）、速率（0.1~3.0x）、音量（0~300%）
   - 全局多音轨 BGM 音乐池混音
   - CRF 17 高质量编码与 Lanczos 高清缩放
   - 自动生成独立批次文件夹并对账校验

## 构建与运行

### 环境要求
- Windows 10 (1903 及以上) / Windows 11
- .NET Framework 4.8 或 .NET SDK (8.0/9.0/10.0)
- FFmpeg 6.0+

### 本地编译
```powershell
dotnet build -c Release
```

输出可执行文件位于 `bin/Release/net48/VideoBatchStudio.exe`。
